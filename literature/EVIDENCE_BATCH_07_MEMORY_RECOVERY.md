# 原文核验批次 07：长期记忆、失败检测与恢复

核验日期：2026-10-02。检索模式为 **rapid-scan（快速定向补充）**。问题限定为：历史信息如何进入预测或策略，系统何时判断执行将要或已经失败，以及所谓“恢复”究竟指提前避险、动作纠正、状态修复还是恢复原任务。本批次不是完整失败恢复综述，也不把预印本结果视为独立复现。

## 1. Mem-World

**身份与机制。** 2026 arXiv 预印本。W-VMem 以腕部视角为中心建立 4D surfel 索引，根据未来动作对应的相机位姿、几何可见性、任务相关性和时间新近性检索历史帧，为多视角动作条件视频预测提供长期上下文。

**主要证据与论文结论。** 五个操作任务中，Mem-World 预测的策略成功率与实体成功率相关系数为 $r=0.97$，Ctrl-World 为 $r=0.85$。策略训练实验每个任务生成 200 条轨迹，经人工成功标注保留 20--30 条；三个长时任务的平均实体成功率从 58\% 提高到 72\%。

**可支撑判断。** 该工作支持“几何相关的历史检索可以改善长时 action-conditioned rollout，并使其在该协议下更适合策略评估与合成数据生成”。

**局限与待核验。** 五任务相关性样本很小，且绝对成功率整体低估实体结果。训练增益包含人工筛选，不是自主闭环恢复。论文明确指出初始腕部视图不足会影响预测，且未施加接触约束，可能在没有对向接触时预测抓取成功。证据位置：第 3.2、4.2--4.3、5 节，图 4--6。

## 2. WorldScape Policy 2.0

**身份与机制。** 2026 arXiv 预印本。模型以近期视频作为短期视觉记忆，并将 VLM 产生的历史组织为全局、局部活动和事件边界表示；检索结果与规划 token 一起形成潜在子目标条件。

**主要证据与论文结论。** RoboTwin 2.0 clean-only 消融中，无记忆平均成功率为 40.91\%，加入短期记忆为 44.67\%，再加入长期事件记忆为 46.25\%，加入潜在子目标推理为 47.89\%。实体部分在 AgileX 双臂 PiPER 上每任务 20 次试验，覆盖衣物与盒子折叠、shell game、积木堆叠和桌面清理。

**可支撑判断。** 该工作支持“短期视觉上下文、事件级进度记忆和子目标推理在同一系统内具有逐步增量”，并提供单平台长时实体执行结果。

**局限与待核验。** 消融使用 clean-only 训练，不能与 clean-plus-randomized headline 直接比较。实体表比较完整系统，没有移除长期记忆的 matched physical ablation，也没有预设失败注入。因此不能据此声称记忆单独造成实体收益或系统具备失败后恢复能力。证据位置：第 3.3、4.1、4.4--4.5 节，表 3--6。

## 3. Failure-Aware RL

**身份与机制。** 2026 arXiv 预印本。系统离线训练任务策略、恢复策略和带约束预测头的 latent world model。在线阶段，世界模型短视 rollout 当前任务策略；预测风险超过阈值时，改为执行恢复策略动作，世界模型和恢复策略保持冻结。

**主要证据与论文结论。** FailureBench 的四个仿真任务中，作者报告相对 Uni-O4 的失败 episode 平均减少 43.6\%。仿真消融把世界模型安全 critic 换成 Recovery RL 的 Q critic，四任务失败 episode 均增加。实体部分在三个 Franka 任务上各训练 50 个 episode，并报告 FARL 相对基线减少 failure state--action pairs；每任务另收集三类、合计 40--80 条示范。

**可支撑判断。** 该工作把世界模型输出明确接到运行时动作门控，支持“短期未来风险预测可以服务于实体在线后训练中的提前干预”。

**局限与待核验。** 摘要中的 73.1\% 指实体训练期间的 failure state--action pairs 降幅，不等同于失败 episode 减少 73.1\%。系统通常在失败前替换动作，论文也明确区分真正的 post-failure recovery 与这类 prevention。实体仅一个平台、三个任务，世界模型消融只在仿真完成；理论结论依赖恢复策略安全概率和安全动作优势等假设。证据位置：第 II、IV、V、VI-B--VI-C 节，式 11--13，表 II--III，图 7。

## 4. ViFailback

**身份与机制。** CVPR 2026 正式论文。ViFailback-8B 监听机器人视频，检测并定位失败，生成链式诊断与文本或视觉符号；经专门训练的 $\pi_{0.5}$ 根据这些外部提示执行纠正。

**主要证据与论文结论。** 数据集包含 58,128 个 VQA 对和 5,202 条实体操作轨迹。三个未出现在 ViFailback 数据中的实体任务各进行 21 次试验并复用相同初始布局。无纠正的两条基线平均成功率为 50.8\% 和 52.4\%；加入 PMC 或 VSF 后为 74.6\% 和 73.0\%。

**可支撑判断。** 该工作支持“失败发生后，外部视觉诊断与可执行纠正提示可以在受控实体协议中提高 VLA 成功率”。它是恢复边界的重要对照：纠正并不必然依赖预测动力学。

**局限与待核验。** 每个条件只有 63 个跨任务试验，三项任务均在同一 ALOHA 系统上。监控间隔、误报、检测延迟和额外计算未形成统一代价比较。完整系统同时依赖诊断模型、符号跟随训练和纠正接口，不能把全部提升归因于某一个部件。证据位置：第 3.1、4.3、5 节，表 4，图 5。

## 5. LIBERO-Recover

**身份与机制。** 2026 arXiv 预印本。基准从模型真实执行失败构造 1,000 余个仿真场景，按所需状态推理深度划分为动作重试、动作适应、对象状态恢复和环境恢复四级。

**主要证据与论文结论。** 六个 VLA/WAM 模型每任务评测 10 次。各模型在 L1/L2 上普遍高于 L3/L4，说明局部动作调整不能替代状态恢复。混合恢复数据训练后，GR00T N1.5 的恢复成功率从 17.8\% 到 21.2\%，OpenVLA-OFT 从 20.8\% 到 25.4\%；同期标准 LIBERO 成功率分别仅从 86.5\% 到 87.2\%，以及从 97.1\% 降至 96.6\%。

**可支撑判断。** 该基准支持将“失败恢复”拆成不同任务终点，并说明标准任务成功和从构造失败状态继续执行是不同评测问题。

**局限与待核验。** 全部实验在 LIBERO 仿真中完成，不能直接推出实体恢复能力。测试从构造失败状态开始，不等同于在线识别自身执行中的失败。论文对 WAM 恢复一致性的解释是可能机制，不是因果消融；“首个”定位未在本轮 rapid-scan 中独立验证。证据位置：第 3.3--3.5、4、5.1--5.2 节，表 1、3，图 6--9。

## 跨论文判断与仍缺证据

1. 长时记忆首先解决的是隐藏状态与进度保持，不应自动写成失败恢复。Mem-World 偏预测持久性，WorldScape Policy 2.0 偏策略进度记忆。
2. FARL 的世界模型用于失败前风险预测和动作替换；ViFailback用于失败后的外部诊断与纠正。两者不能合并为同一种“self-recovery”。
3. LIBERO-Recover 提供恢复层级，但当前证据仍缺少跨平台实体协议，以及在同一系统中同时测量检测、恢复状态、恢复原任务、干预时间和事故严重度。
4. 下一轮优先检索 `physical robot state restoration after failure benchmark`、`world model online failure detection recovery ablation` 和 `cross-platform robot failure recovery`，并记录误报、漏报、恢复时长、人工干预次数与最终任务完成率。

## 检索与证据边界

本轮从现有目录中的 Mem-World、WorldScape Policy 2.0、ViFailback 和 LIBERO-Recover 出发，以 `world model failure recovery real robot`、`long-term memory world action model` 和 `robot failure recovery benchmark` 定向补查 Failure-Aware RL，再回到 arXiv 与 CVF 原文。五篇形成“记忆保持--进度跟踪--提前避险--失败后纠正--恢复层级评测”的机制样本，不构成穷尽检索或性能排行榜。
